# 产品定义

- 日期: 2026-07-26
- 想法一句话: 一个带 Web UI 的多 agent 协作平台,用户作为项目 owner 把可配置的角色 agent 拉进项目组,agent 们在群组内平等协作、自主接力完成软件交付。
- 目标用户: 个人开发者(自己用它组建"虚拟小团队"提效:从需求整理到代码实现的多角色协作)
- 要解决的问题: 单 agent coding 工具(Cursor/Copilot)缺乏角色分工与流程编排;复杂任务需要不同视角(PM 理需求、架构师设计、开发实现、QA 验证),但现有工具无法表达"团队协作"与"角色交接"
- 成功标准: 用户能创建项目组、拉入多个角色 agent、派发一个任务后,在 UI 上观察到多角色自主接力协作(各自产出可见、交接可见)
- 用户确认: 2026-07-26

## MVP 边界(做什么)

- 可配置的 Agent(五要素):名字 + 职责描述(system prompt)+ 可用工具(从内置池勾选)+ 模型供应商(per-agent)+ harness/skill 集合
- 模型供应商:Provider 抽象层,第一版接入 zhipuai-coding-plan(GLM,OpenAI 兼容接口)
- 项目组(Team):由多个 agent + 1 个 owner(用户)组成
- 群组内协作:agent 完成产出后产出物落盘并发到项目群;agent 看群内成员与任务状态后自主决定下一步交给谁;owner 可随时介入但不逐节点审批
- Web UI:管理 agent 定义、管理项目组、实时观察角色产出与交接(群聊消息流形态)
- 内置角色模板:PM、架构师、开发工程师、QA(开箱即用,可改可加)

## 不做清单(明确排除)

- 不做 IDE 插件/编辑器集成(第一版独立 Web 应用)
- 不做自动部署/CI 集成
- 不做实时多用户协作(第一版单 owner)
- 不做 agent 自进化的完整能力(第一版;长期方向保留,架构预留扩展点)
- 不做语音/视频
